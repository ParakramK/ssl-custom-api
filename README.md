# SSL Custom API

Go REST API over SAP Business One data: customer/sales reporting from SAP HANA, gatepass/weighbridge reporting from MySQL.


## Setup

Configure environment:

```bash
API_KEY=
HANA_HOST= HANA_PORT=30015 HANA_USER= HANA_PASSWORD= HANA_SCHEMA=
MYSQL_HOST= MYSQL_PORT=3306 MYSQL_USER= MYSQL_PASSWORD= MYSQL_DATABASE=
```

Run:

```bash
go run ./cmd/api
```

Listens on `:8080`. Docs at `/docs`, OpenAPI at `/openapi.json`.

## GORM models

`internal/gatepass/models` maps the existing MySQL schema (table/column names preserved, no migrations).

## Codegen

Type-safe queries live in `internal/gatepass/query`, generated by `gorm.io/gen`:

```bash
go run ./cmd/gentool
```

## Tech Stack

- Go, Huma v2 + Fiber
- SAP HANA (go-hdb), MySQL (GORM)
- gorm.io/gen query builder
